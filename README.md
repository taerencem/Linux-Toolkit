# Linux Administration Toolkit

A collection of Bash scripts, configuration files, and troubleshooting guides for Linux server administration.  
Built to demonstrate practical sysadmin skills used in enterprise environments.

---

## 🔧 Purpose
This toolkit highlights Linux administration skills including:

- User and group management  
- Log rotation and system monitoring  
- Backup automation  
- Cron job scheduling  
- Firewall and security hardening  
- Network troubleshooting  

---

## 🧰 Technologies Used
- Ubuntu / Debian  
- CentOS / RHEL  
- Bash  
- systemd  
- SSH  
- iptables / ufw
